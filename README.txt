Substitua no GitHub os arquivos:

O que mudou:
- Leg press agora aparece em uma máquina de leg press, com posição flexionada e estendida.
- As ilustrações deixaram de usar o mesmo boneco genérico para todos os exercícios.
- Cada grupo de movimento possui desenho/posição próprios: cadeira extensora, flexora, stiff, ponte, abdutora, puxada, remada, supino, elevações, braços, core, step, agachamento, passada etc.
- A animação alterna as duas posições principais do movimento para ficar fácil de entender.
- Cache atualizado para V5.

Depois do commit, espere o GitHub Pages atualizar e faça uma atualização forçada da página.
