# Larissa Fit

Versão inicial de um app pessoal de treino + água.

## Incluído
- Programa 3x por semana
- Programa 5x por semana
- Fases e semanas
- Explicação simples de execução
- Alternativas quando o aparelho não existir
- Registro de carga
- Registro de treino
- Controle diário de água
- Meta de água configurável
- Lembretes no navegador quando suportado
- Instalação como PWA
- Dados salvos no próprio aparelho via localStorage

## Importante
Esta primeira versão salva os dados localmente no aparelho/navegador.
Para sincronizar entre dispositivos e ter um painel administrativo completo na nuvem,
a próxima etapa é conectar um banco de dados e autenticação.

## Como testar
Abra `index.html` em um servidor local. Para PWA/notificações, use HTTPS ou localhost.
